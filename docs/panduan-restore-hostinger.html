Kembalikan Desain Website

Restore backup Hostinger, lalu kirim 15 file live ke Aira.

Catatan: gambar tampilan di bawah adalah ilustrasi. Tampilan hPanel asli bisa sedikit berbeda, tapi nama menunya sama. Kotak bergaris emas = yang diklik.

A. Restore backup (mengembalikan desain)

1

Buka hpanel.hostinger.com → menu Websites → klik Manage di alqomar.sch.id.

hPanel · Websites
🌐 alqomar.sch.idManage
2

Menu kiri: Files → Backups.

alqomar.sch.id
  • Dashboard
  • Files ▾
  • Backups
  • File Manager
Pilih jenis backup…
3

Pilih File backups (bukan Database), pilih tanggal 21 September 2026, klik Select files.

Backups
File backups
Tanggal: 21 Sep 2026 ▾Select files

Tidak ada 21 Sep? Pilih tanggal terakhir sebelum Bapak upload ZIP pertama.

4

Centang folder public_html → klik Restore. Tunggu sampai selesai.

Pilih file untuk dipulihkan
📁 public_html
📁 logs
Restore
5

Buka alqomar.sch.id, tekan Ctrl+Shift+R. Desain harus sudah kembali seperti sebelumnya.
